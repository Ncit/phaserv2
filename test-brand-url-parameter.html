🔧 How It Works

The system now checks for a brand URL parameter:

  • No parameter or ?brand=winline → Uses Winline assets
  • ?brand=betboom → Uses Betboom assets
  • Any other value defaults to Winline

Example URLs:

  • index.html → Winline (default)
  • index.html?brand=winline → Winline
  • index.html?brand=betboom → Betboom
  • index.html?brand=anything → Winline (default)
