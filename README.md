# Phaser Poker Game

This is the deployed version of the Phaser Poker Game.

Visit: https://ncit.github.io/phaserv2/

## Game Features
- Texas Hold'em Poker
- AI Bot opponents
- Multiplayer functionality
- Beautiful UI with animations
- Mobile-friendly design

## Game Modes
- **Fast Game**: Quick matches with AI opponents
- **Friends Game**: Play with friends online
- **AI Bot**: Practice against intelligent AI

## Technologies
- Phaser 3 Game Engine
- Socket.io for multiplayer
- VK Bridge integration
- Responsive design

## How to Play
1. Choose your game mode
2. Set your bet amount
3. Play Texas Hold'em poker rules
4. Win chips and climb the leaderboard!

Enjoy the game! 🃏
