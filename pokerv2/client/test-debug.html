📱 Eruda Integration

Eruda is a mobile web debugging tool that provides:

  • Console: View console logs and errors
  • Network: Monitor network requests and WebSocket events
  • Elements: Inspect DOM elements
  • Resources: View localStorage, sessionStorage, and cookies
  • Info: Device and browser information
  • Snippets: Run JavaScript code snippets

How to use:

  1. Tap the Eruda icon in the bottom-right corner
  2. Use the Network tab to monitor WebSocket connections
  3. Use the Console tab to view debug logs
  4. Use the Elements tab to inspect game UI

🔍 Debug API Reference

Global debug object provides these methods:

Network Debugging:

debug.network.getStatus() - Get connection status
debug.network.getLogs() - Get network logs
debug.network.clearLogs() - Clear network logs

Game Debugging:

debug.game.getState() - Get current game state
debug.game.getPlayers() - Get player list
debug.game.getCurrentPlayer() - Get current player
debug.game.forceAction(action, amount) - Force game action

Performance Debugging:

debug.performance.getMetrics() - Get performance metrics
debug.performance.startTimer(name) - Start timer
debug.performance.endTimer(name) - End timer
debug.performance.getTimers() - Get active timers

Error Debugging:

debug.errors.getErrors() - Get error logs
debug.errors.clearErrors() - Clear error logs
debug.errors.simulateError() - Simulate error

Utility Functions:

debug.utils.reload() - Reload page
debug.utils.clearStorage() - Clear storage
debug.utils.exportData() - Export debug data
debug.utils.importData(data) - Import debug data
