# PokerV2 - Phaser.js Poker Game

A multiplayer poker game built with Phaser.js, featuring AI bots and real-time gameplay.

## 🎮 Live Demo

The game is deployed on GitHub Pages and can be accessed at:
https://ncit.github.io/phaserv2/

## 🚀 Features

- **Multiplayer Poker**: Real-time multiplayer gameplay with Socket.IO
- **AI Bots**: Intelligent AI opponents for single-player games
- **Multiple Game Modes**: Fast game, friends game, and training modes
- **Responsive Design**: Works on desktop and mobile devices
- **VK Integration**: Built for VK platform integration

## 🛠️ Technology Stack

- **Frontend**: Phaser.js 3, HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Socket.IO
- **UI**: Custom UI components with responsive design
- **Assets**: Custom poker card graphics and game assets

## 📁 Project Structure

```
pokerv2/
├── src/                    # Source code
│   ├── scenes/            # Phaser.js game scenes
│   ├── managers/          # Game managers (UI, Network, etc.)
│   ├── config/            # Game configuration files
│   └── utils/             # Utility functions
├── assets/                # Game assets (images, fonts, etc.)
├── dependencies/          # External libraries
├── server/                # Backend server code
└── index.html            # Main entry point
```

## 🎯 Game Modes

1. **Fast Game**: Quick matchmaking with random players
2. **Friends Game**: Private rooms for friends
3. **AI Bot Game**: Single-player against AI opponents
4. **Training Mode**: Practice mode with tutorials

## 🔧 Development

### Prerequisites
- Node.js (for server)
- Modern web browser

### Running Locally
1. Clone the repository
2. Navigate to the `pokerv2` directory
3. Start the server: `cd server && npm install && npm start`
4. Open `index.html` in your browser

### Building for Production
The game is automatically deployed to GitHub Pages when changes are pushed to the `network_v3`, `master`, or `main` branches.
